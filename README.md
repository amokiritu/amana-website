# amana-website

The public website for Amana, served at https://amana-erp.com by GitHub Pages from `main`.

| Page | File |
|---|---|
| Home | `index.html` |
| Amana for Churches | `church/index.html` |
| Amana for Schools | `school/index.html` |
| Amana for Rental | `rental/index.html` |
| GariHub | `garihub/index.html` (and `garihub/photo-credits.html`) |

- `css/site.css`: the look of every page (colours per product, type, layout).
- `images/<product>/`: screenshots, taken from each app's preview on made-up sample books (Sample Church,
  Sample School, Sample Motors). Never use screenshots of real books here.
- The car photos inside GariHub's screenshots are openly licensed photos from Wikimedia Commons; their
  photographers are credited on `garihub/photo-credits.html`. Keep that page if those screenshots stay.
- `CNAME`: tells GitHub Pages the site's address (amana-erp.com).

To change a page, edit its file and push to `main`; GitHub publishes it within a minute or two.
