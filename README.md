# amana-website

The public website for Amana ERP, served at https://amana-erp.com by GitHub Pages.

- `index.html`: the whole page (text, styles and the screen tabs).
- `images/`: the logo and the screenshots. Screenshots come from the app's preview on made-up sample books
  (Sample Church, Sample School); never use screenshots of real books here.
- `CNAME`: tells GitHub Pages the site's address (amana-erp.com).

To change the page, edit `index.html` and push to `main`; GitHub publishes it within a minute or two.
